## ✨ Antd 完全移除 (2026-01-08)

### 目标
移除 Ant Design 依赖，减少包体积

### 效果
- **Antd 体积**: 435.78 kB → 0 (gzip: 137.80 kB → 0)
- **替代方案**: 自定义轻量级组件 (~20 kB)
- **净收益**: -112.45 kB (gzip) | -42.6% 包体积

### 转换的组件

| Antd 组件 | 替代方案 |
|-----------|---------|
| Input | 自定义搜索框 |
| Carousel | 自定义轮播图 |
| Pagination | 自定义分页 |
| Tooltip, Popover | 浮层组件 |
| SearchOutlined | SVG 图标 |

### 技术实现

**自定义组件特点**：
- 保持与 Antd 相同的 API 和视觉效果
- 按需实现所需功能，无冗余代码
- 完全类型安全（TypeScript）

**相关文件**：
```
src/components/
├── Input/
├── Carousel/
├── Pagination/
├── Tooltip/
└── Popover/
```
